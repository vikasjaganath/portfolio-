# Portfolio: Vikas HJ

A plain HTML, CSS and JavaScript portfolio. No frameworks, no build step.

## Run it
Open `index.html` in a browser, or serve the folder with any static server.

## Fill it in
Search the project for `[ADD` and replace every placeholder with your real details (bio, skills, projects, links, email, location). Put images in `assets/images/`.

## Contact form
Validation works out of the box. To send messages, set `FORM_ENDPOINT` at the top of the form section in `js/script.js` to a form service URL (Formspree, Getform, your own API). It posts JSON with `name`, `email` and `message`.

## Deploy
Upload the folder to GitHub Pages, Netlify or Vercel as a static site.
